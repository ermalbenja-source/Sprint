Rikthe menunë fillestare

Zëvendëson gjithçka në panel me menunë origjinale të faqes. Nuk prek Supabase derisa të shtypësh «Ruaj».

Si lidhet Supabase

  1. Krijo një projekt falas te supabase.com.
  2. SQL Editor → ngjit skedarin supabase/schema.sql nga repo-ja → Run.
  3. Authentication → Users → Add user: email-i dhe fjalëkalimi me të cilin hyn këtu.
  4. Project Settings → Data API → kopjo Project URL dhe çelësin anon te shared/config.js, pastaj ribëj publikimin.
  5. Kthehu këtu, hyr, dhe shtyp «Dërgo tani» më sipër.
